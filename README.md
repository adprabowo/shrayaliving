# Shraya Living

Landing page untuk Shraya Living, cluster hunian di Kenali Besar, Kota Baru, Jambi.

Live: https://shrayaliving.vercel.app

## Development

```bash
npm install
npm run dev
```

Buka http://localhost:3000. Deploy otomatis ke Vercel setiap push ke `main`.

Desain mengikuti skill `landing-page-design` dari [elayadesign/ai-design-skills](https://github.com/elayadesign/ai-design-skills).
